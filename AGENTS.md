# Repository collaboration rules

- Communicate with the user in Simplified Chinese, including analysis, plans, progress, explanations, test results and final responses.
- Keep source identifiers (variables, functions, classes) and API paths in conventional English.
- Product UI, README, formal technical documentation and Git commit messages should normally be in English for international users.
- Important technical terms may remain in English; explain them in Chinese when communicating with the user.
- Preserve these standing rules in future Codex sessions. Merge additions rather than replacing existing instructions.
- Do not push to GitHub, create remote pull requests or deploy without explicit user authorization.
